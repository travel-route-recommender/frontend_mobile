# 모바일 친구·궁합 테스트

마이페이지의 친구 영역과 완료된 7단계 원본 응답에서 계산한 여행 성향 결과를 이용해 친구 여행 궁합을 계산한다. 현재 친구와 계산 엔진은 mock/local이며 백엔드 endpoint나 DTO는 정의하지 않는다.

## 화면 흐름

1. 마이페이지 `친구 관리`에서 가상 친구를 저장하거나 해제한다.
2. `테스트 다시 하기` 아래의 `친구와 궁합 테스트`로 진입한다.
3. 저장된 친구 중 한 명 이상을 복수 선택한다.
4. `궁합 테스트 시작` 후 로딩 화면을 표시한다.
5. 전체 점수와 5단계 궁합 유형을 보여준다.
6. 상세 버튼에서 7개 카테고리 점수를 확인한다.
7. 결과 화면의 버튼으로 홈 또는 친구 선택 화면으로 이동한다.

route:

- `/friends`
- `/tests/compatibility`
- `/tests/compatibility/result`

## 친구 상태

`useFriendCompatibilityStore`가 사용자별 `savedFriendIdsByUserId`를 AsyncStorage에 저장한다. 현재 가상 친구는 윤지(`user-jiyoon`), 민석(`user-minjae`), 현호(`user-hyunho`), 수현(`user-suhyeon`)이며 각 친구에게 완성된 7단계 mock 결과가 준비되어 있다. Store v2 migration은 기존 목록에 새 친구 현호·수현만 추가하고 기존 친구의 저장·해제 상태는 유지한다. 최신 궁합 결과는 화면 이동에만 필요한 비영속 상태다.

## 궁합 계산

나와 각 친구의 점수를 먼저 비교한 뒤, 여러 친구를 선택한 경우 카테고리별 평균을 계산한다.

| 카테고리 | 비교 방식 |
|---|---|
| 일정 밀도 | 일정 밀도 점수 차이 |
| 이동 방식 | 선택 수단의 Jaccard 유사도 |
| 숙소 스타일 | 숙소 3축 유사도 평균 |
| 도전 성향 | 검증된 곳↔새로운 곳 점수 차이 |
| 체력 수준 | LOW/NORMAL/HIGH 점수 차이 |
| 예산 소비 | 카테고리 배분의 total variation 유사도 |
| 여행지 탐색 | 명소·로컬 점수 유사도 평균 |

전체 점수는 7개 카테고리의 동일 가중치 평균이다.

| 점수 | 궁합 유형 |
|---:|---|
| 0~19 | 조율이 많이 필요한 사이 |
| 20~39 | 차이를 즐길 수 있는 사이 |
| 40~59 | 적당히 맞춰가는 사이 |
| 60~79 | 꽤 잘 맞는 여행 메이트 |
| 80~100 | 찰떡 여행 메이트 |

## 백엔드 계약 경계

현재 `mock`은 프론트 내부 계산 입력으로 로컬 결과를 반환하고 `api/hybrid`는 계약 대기 오류를 반환한다. 전송 payload를 미리 정의하지 않으며 실제 endpoint와 요청·응답 DTO가 확정되면 별도 API adapter를 추가한다. 화면과 순수 계산 함수는 해당 adapter와 분리한다.

## 검증

`npm run verify:preference-compatibility`는 7단계 특징값, 원본 응답 재계산, 호환 projection, 동일 성향 100점, 7개 카테고리, 복수 친구 평균과 5개 유형 경계를 검증한다.
