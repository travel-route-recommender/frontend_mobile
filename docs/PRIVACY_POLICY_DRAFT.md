## 6. 외부 로그인·지도·관광 서비스

카카오·Apple 로그인 처리 과정에서 인증 토큰과 인증 제공자 계정 정보가 각 제공자 및 두리 서버에서 처리됩니다. 장소·경로 정보를 제공하기 위해 카카오 지도 화면과 카카오·공공 관광 API를 사용합니다. 검색 조건과 장소 좌표가 외부 제공처에 전달될 수 있고 지도 화면 통신 과정에서 IP 주소·사용자 에이전트가 제공처에 전달될 수 있습니다. 앱과 백엔드 코드는 지도·관광 API 요청에 두리 내부 사용자 ID를 의도적으로 포함하지 않습니다.

## 7. 기기 내 저장

리프레시 토큰은 운영체제 보안 저장소에 저장합니다. 화면 상태, 최근 검색, 작성 중인 여행 데이터 일부는 앱 로컬 저장소에 보관될 수 있습니다. 설치 식별자는 기기 보안 저장소에서만 사용되고 현재 코드상 서버 전송은 확인되지 않았습니다. 로그아웃·계정 삭제 시 계정 범위의 로컬 개인정보를 삭제합니다.

## 8. 파기

처리 목적이 끝난 개인정보는 지체 없이 복구하기 어려운 방법으로 삭제합니다. 계정 삭제 시 계정 식별정보, 설문·성향, 저장 장소와 인증 세션을 삭제 또는 익명화하고 탈퇴자가 업로드한 티켓·문서 파일을 삭제합니다. 공동 여행방의 일정 등 공동 데이터는 다른 구성원을 위해 유지되며 탈퇴자는 익명화됩니다. 탈퇴자가 방장인 여행방은 닫힘 처리됩니다. 법정 보존 정보는 별도로 분리합니다. 운영 백업에서의 최종 삭제 기간은 `{{BACKUP_RETENTION}}`으로 확정합니다.

## 9. 이용자 권리와 행사 방법

이용자는 앱의 프로필·마이페이지 또는 개인정보 담당 연락처를 통해 개인정보의 열람, 정정, 삭제, 처리정지를 요구하고 계정을 삭제할 수 있습니다. 대리인을 통한 요청, 본인 확인, 이의 제기 절차는 확정된 개인정보 담당 연락처로 안내합니다.

## 12. 자동 수집 장치
