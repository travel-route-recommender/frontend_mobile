# iOS 1.0.1 업데이트 기록

## 변경 범위

- 브랜치: `ios_release` (main 병합 없음)
- 앱 코드 커밋: `d2e208092b4e3736b0b501c91e5b381996d0c2ab`
- 성향 저장 요청에서 빠진 필수 점수·체력 수준·일정 선호 필드를 전송한다.
- 상단 일정 추가 팝업의 본문이 남은 높이를 차지하도록 수정한다. 후보 목록의 높이가 0으로 줄고 검색창과 버튼이 겹치던 현상을 해결했다.
- 백엔드 코드, Android 배포, 공동 작성자 정보는 변경하지 않았다.

## 검증

- `typecheck`, `lint`, `git diff --check` 통과.
- 성향 저장 16개, 성향 호환성 50개, 여행방 성향 13개 검사 통과.
- 일정 편집 100개 및 충돌 검사, 일정 API 계약 73개 검사 통과.
- 여행 생성, 장소 탐색, 인증 세션 검사 통과.
- 성향 기반 자동 채우기 61개, 그룹 성향 59개 및 추가 검증 통과.
- iPhone 17 Pro / iOS 26.5 시뮬레이터에서 운영 API에 연결하여 확인했다.
  - 수정 전: 후보 2개가 있어도 상단 팝업의 목록이 보이지 않았다.
  - 수정 후: 후보 2개 표시, ‘광안리’ 검색, 후보 선택, 일정 편집 화면 진입 성공.
  - 승인된 ‘부산 주말 여행 (시연)’ 방에 첫째 날 광안리 일정을 추가했다. 저장 성공 안내와 서버 일정 `v7`, 첫째 날 일정 1개를 확인했다.
  - 검색 결과 없음 안내, 팝업 닫기, 저장된 일정 유지 확인.
- App Store Connect에 심사 연락처·로그인 필수 설정·테스트 계정·메모가 등록되어 있음을 EAS Metadata 조회로 확인했다.
- 등록된 심사용 계정으로 운영 로그인 API에서 HTTP 201 및 토큰 발급을 확인했다. 계정 비밀번호는 Git에 기록하지 않는다.
- 로컬 `verify:ios-release`의 심사 정보 경고는 `store.config.json`에 계정 정보를 보관하지 않기 때문에 남는다. 위 외부 확인과 구분한다.
- 이번 변경의 UI 검증은 시뮬레이터에서 진행했으며, 새 TestFlight 빌드의 실기기 검증은 포함하지 않는다.
